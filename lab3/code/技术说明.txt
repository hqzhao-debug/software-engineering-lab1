校园循物：实现与维护说明

性质
本文件是软件技术文档，不是实验报告，不包含冒充本人经历的反思、人工修改或人工验收结论。

一、结构与数据
campus_market.service.Market 合成商品、交易、管理、账号及基础服务。
cli.py 负责命令行参数、中文提示、JSON 输出与本地会话。webapp.py 为本地浏览器 UI 提供 HTTP 入口，web/ 保存 HTML/CSS/JavaScript 页面，web_seed.py 创建独立的虚构演示数据。两种界面共用 Market；业务授权集中在服务层，因此直接调用 Python API 同样受限制。
models.py 定义状态与金额、字段校验；价格用 Decimal 解析和整数分汇总，不用浮点数累计。
db.py 创建 SQLite 表、外键和索引；每次业务操作使用独立连接，便于测试跨连接竞争。
products.content_json 保存当前本人编辑内容，submitted_versions 保存正式提交的不可变版本。管理员只读取已提交内容，不能把当前私人草稿误当作管理内容。
review_submissions 保存每次送审批次；旧批次处理不能覆盖当前批次。
reservations 保存创建时快照与后续状态时间。快照不固化对方邮箱；邮箱按访问者、交易归属及当前状态动态返回。
images 使用数据库 BLOB 持久化，引用历史不随商品修改覆盖，不提供清理历史图片的操作。

二、一致性
写操作使用 BEGIN IMMEDIATE，在事务内重查会话、账号、归属、商品与预约状态。SQLite 通过单写者锁串行化相互冲突的写事务，与实验二 PostgreSQL 的行锁实现方式不同。
按 product_id 建立“有效预约”与“完成预约”两条部分唯一索引，防止同一商品同时占用两次或成交两次。
预约/商品状态变化、成功日志与幂等结果共同提交；失败回滚后单独记录失败日志。数据库本身不可写时无法保证失败日志落盘，不能把这种情况报告为业务成功。
请求键范围为操作者、操作和 key；参数先规范化为稳定 JSON 摘要。同键不同内容拒绝，成功重试返回原对象当前状态，不能恢复过期状态或重复计入统计。
商品行版本处理旧编辑请求，内容版本处理买家确认的商品内容，审核批次处理当前送审结论；三者各自服务于不同的并发边界。

三、身份与访问
密码使用带独立随机盐的 PBKDF2-HMAC-SHA256；验证使用常数时间摘要比较。返回值与日志不包含密码或其哈希。
会话和验证码使用随机令牌，数据库持有其哈希。CLI 会话文件是本地凭据，采用 0600 权限，并记录所属数据库，防止误用另一数据库的会话。
登录第五次连续错误固定锁定 15 分钟，锁内尝试不延时。每个会话独立计算 30 分钟闲置；后台读取可指定不续期。
普通用户只能操作本人商品及本人相关预约，管理员不能交易或读取私人草稿。公开查询范围仅在售；邮箱、学号及私密交易不向无关用户返回。
取消/拒绝后不返回对方邮箱；程序不能撤销此前参与人已经看到或自行保存的信息。
管理员封禁取消关联有效预约，撤销会话并下架卖家的未成交非草稿商品。解封不自动恢复预约或上架，必须重新审核。
成交后违规只添加记录和限制，不回退交易终态，不冲减已成交统计。

四、输入与运行决策
官方校园域名未在原需求中确定，默认 campus.example 仅作开发数据；实际环境显式配置。
用户名不允许 @，避免用户名与邮箱登录入口产生歧义；邮箱规范化为小写。这是实现决策，不是伪称原访谈已确认的新需求。
未额外虚构用户名、密码、留言的业务长度阈值。标题、描述、价格、分类、成色、图片数量和大小遵守原需求的给定范围。
本地 outbox 为开发适配器，不能验证真实邮箱归属。可选 SMTP 适配器需真实服务配置，本次演示不把本地邮件当作真实邮件收发证据。
当前版本不配置验证码自动过期、重发或业务自动取消；这些规则在原需求中未明确，后续可经确认扩展。
图形界面通过仅监听 127.0.0.1 的本地 HTTP 服务打开浏览器。HTTP 入口校验请求来源和防伪令牌，会话使用 HttpOnly / SameSite cookie；请求仍调用原服务进行账号、归属和状态验证。CLI、本地服务与数据库部署在同一可信本机环境，操作系统文件访问权限仍是信任边界，不能将此程序直接描述为多租户互联网服务。

五、图形演示与可复现
双击作业三目录的一键演示.command，或执行 python3 -m campus_market.webapp --demo --data-dir data/gui-demo，可打开图形界面。Terminal 保持本地服务，按 Control+C 停止。
图形演示使用单独的 data/gui-demo 目录；首次创建后保留操作。演示类型标记及随机密码仅存本地0600元数据；无法识别的现有目录拒绝初始化，避免覆盖真实数据。
执行 python3 -m campus_market.demo 观察完整链路；默认临时数据库用后清除，--directory 可保留独立演示数据。
执行 python3 -m unittest discover -s tests -v 运行自动化用例。请以实际生成的测试输出为结果，不能从测试文件存在推定测试已通过。
演示会检查重复请求、非法角色操作、终态重试、取消邮箱隐藏、成交后违规和重开数据库读取。其结果不代表真实多人易用性或浏览器兼容性测试。
